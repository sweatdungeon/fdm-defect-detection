fdm_defect.cnn

Pretrained CNN classifier (MobileNetV3-Small, or ResNet-18) for under-extrusion.

The ImageNet classifier's last layer is replaced by a single-logit layer, and sigmoid(logit) is the probability of under-extrusion. By default only the head is trained and the backbone is frozen:

  • MobileNetV3-Small: the head is model.classifier (pretrained Linear(576, 1024) + Hardswish + Dropout + new Linear(1024, 1)); the backbone is model.features.
  • ResNet-18: the head is the new model.fc = Linear(512, 1).

Two details matter for correctness:

  1. Frozen BatchNorm must stay in eval mode. model.train() puts every BatchNorm layer in training mode, where it normalises with the current batch's statistics and overwrites the ImageNet running statistics, even if its weights are frozen. set_train_mode() puts frozen BatchNorm layers back into eval mode.
  2. Always start from pretrained weights. MobileNetV3's BatchNorm momentum is 0.01, so running statistics move only 1% per batch. From random weights they lag far behind the changing activations, and the eval-mode network collapses to near-constant outputs.

Training uses BCEWithLogitsLoss with pos_weight = n_good / n_defective, AdamW, random horizontal flips and brightness changes, and early stopping on validation loss that restores the best weights.

 94def build_model(arch="mobilenet_v3_small", pretrained=True, freeze_backbone=True):
 95    """Build a CNN with a single-logit head.
 96
 97    Parameters
 98    ----------
 99    arch : {"mobilenet_v3_small", "resnet18"}, default "mobilenet_v3_small"
100        Backbone architecture.
101    pretrained : bool, default True
102        Load ImageNet weights (downloaded once, then cached by torchvision).
103        Only use False for tests of the mechanics; see the module docstring.
104    freeze_backbone : bool, default True
105        If True, only the head's parameters have ``requires_grad=True``.
106        If False, the whole network is trainable (full fine-tune).
107
108    Returns
109    -------
110    torch.nn.Module
111        Model mapping ``(B, 3, H, W)`` normalised images to ``(B, 1)`` logits.
112
113    Raises
114    ------
115    ValueError
116        If ``arch`` is not in :data:`ARCHS`.
117    """
118    if arch == "mobilenet_v3_small":
119        model = mobilenet_v3_small(weights=MobileNet_V3_Small_Weights.IMAGENET1K_V1 if pretrained else None)
120        model.classifier[-1] = nn.Linear(model.classifier[-1].in_features, 1)
121        head = model.classifier
122    elif arch == "resnet18":
123        model = resnet18(weights=ResNet18_Weights.IMAGENET1K_V1 if pretrained else None)
124        model.fc = nn.Linear(model.fc.in_features, 1)
125        head = model.fc
126    else:
127        raise ValueError(f"unknown arch {arch!r}; choose from {ARCHS}")
128
129    if freeze_backbone:
130        head_params = {id(p) for p in head.parameters()}
131        for p in model.parameters():
132            p.requires_grad = id(p) in head_params
133    return model

136def set_train_mode(model):
137    """Put ``model`` in training mode, but keep frozen BatchNorm layers in eval mode.
138
139    A BatchNorm layer counts as frozen when none of its parameters require
140    gradients. In eval mode it keeps normalising with its pretrained running
141    statistics instead of batch statistics, and those statistics are not
142    updated.
143
144    Parameters
145    ----------
146    model : torch.nn.Module
147
148    Returns
149    -------
150    torch.nn.Module
151        The same model, for chaining.
152    """
153    model.train()
154    for module in model.modules():
155        if isinstance(module, nn.modules.batchnorm._BatchNorm):
156            params = list(module.parameters())
157            if params and not any(p.requires_grad for p in params):
158                module.eval()
159    return model

162def normalise(x):
163    """Apply ImageNet normalisation (subtract channel mean, divide by channel std).
164
165    Parameters
166    ----------
167    x : torch.Tensor
168        Image of shape ``(3, H, W)`` or batch ``(B, 3, H, W)`` with values in [0, 1].
169
170    Returns
171    -------
172    torch.Tensor
173        Normalised tensor of the same shape, as the pretrained weights expect.
174    """
175    return (x - IMAGENET_MEAN) / IMAGENET_STD

178def augment_image(x, generator=None):
179    """Random horizontal flip and brightness change.
180
181    Parameters
182    ----------
183    x : torch.Tensor
184        Image of shape ``(3, H, W)`` with values in [0, 1].
185    generator : torch.Generator, optional
186        Source of randomness, for reproducibility.
187
188    Returns
189    -------
190    torch.Tensor
191        Augmented image, same shape, values clipped to [0, 1].
192    """
193    if torch.rand(1, generator=generator).item() < 0.5:
194        x = x.flip(-1)
195    lo, hi = BRIGHTNESS_RANGE
196    factor = lo + (hi - lo) * torch.rand(1, generator=generator).item()
197    return (x * factor).clamp(0.0, 1.0)

200class FrameDataset(Dataset):
201    """Images and labels from a metadata table, as normalised tensors.
202
203    Resized images are cached in memory as uint8 the first time they are read
204    (about 48 KB each at 128 px), so JPEG decoding happens once, not every
205    epoch. The cache and the augmentation generator live in this object, so
206    use it with ``num_workers=0`` (the default in :func:`train_model`).
207
208    Parameters
209    ----------
210    df : pandas.DataFrame
211        Metadata with ``path`` and ``has_under_extrusion`` columns, e.g. from
212        :func:`fdm_defect.data.load_metadata` with ``image_dir`` set.
213    size : int, default ``config.DEFAULT_IMAGE_SIZE``
214        Image side length.
215    augment : bool, default False
216        Apply :func:`augment_image` to each item.
217    seed : int, default ``config.DEFAULT_SEED``
218        Seed for the augmentation generator.
219    """
220
221    def __init__(self, df, size=config.DEFAULT_IMAGE_SIZE, augment=False, seed=config.DEFAULT_SEED):
222        missing = [c for c in ("path", LABEL_COLUMN) if c not in df.columns]
223        if missing:
224            raise ValueError(f"df is missing columns {missing}; load it with image_dir set")
225        if len(df) == 0:
226            raise ValueError("df has no rows")
227        self.paths = df["path"].tolist()
228        self.labels = torch.tensor(df[LABEL_COLUMN].to_numpy(), dtype=torch.float32)
229        self.size = size
230        self.augment = augment
231        self.generator = torch.Generator().manual_seed(seed)
232        self._cache = {}
233
234    def __len__(self):
235        """Number of images."""
236        return len(self.paths)
237
238    def __getitem__(self, i):
239        """Return ``(image, label)``: a normalised ``(3, size, size)`` float32 tensor and a float 0/1 label."""
240        if i not in self._cache:
241            # load_image returns float32 = uint8 / 255, so this round trip is exact.
242            img = np.round(load_image(self.paths[i], self.size) * 255).astype(np.uint8)
243            self._cache[i] = torch.from_numpy(img).permute(2, 0, 1).contiguous()
244        x = self._cache[i].float() / 255.0
245        if self.augment:
246            x = augment_image(x, self.generator)
247        return normalise(x), self.labels[i]

250def compute_pos_weight(labels):
251    """``pos_weight`` for ``BCEWithLogitsLoss``: number of negatives / positives.
252
253    This makes the defective class carry the same total weight in the loss as
254    the good class.
255
256    Parameters
257    ----------
258    labels : array_like
259        0/1 labels.
260
261    Returns
262    -------
263    float
264
265    Raises
266    ------
267    ValueError
268        If either class is absent.
269    """
270    labels = np.asarray(labels)
271    n_pos = int((labels == 1).sum())
272    n_neg = int((labels == 0).sum())
273    if n_pos == 0 or n_neg == 0:
274        raise ValueError(f"need both classes, got {n_neg} negatives and {n_pos} positives")
275    return n_neg / n_pos

278@torch.no_grad()
279def _mean_loss(model, loader, criterion, device):
280    """Mean loss over a loader with the model in eval mode."""
281    model.eval()
282    total, n = 0.0, 0
283    for x, y in loader:
284        x, y = x.to(device), y.to(device)
285        total += criterion(model(x).squeeze(1), y).item() * len(y)
286        n += len(y)
287    return total / n

290def train_model(
291    model,
292    train_df,
293    val_df,
294    size=config.DEFAULT_IMAGE_SIZE,
295    epochs=30,
296    batch_size=64,
297    lr=1e-3,
298    weight_decay=1e-4,
299    patience=5,
300    augment=True,
301    seed=config.DEFAULT_SEED,
302    device=None,
303    verbose=False,
304):
305    """Train ``model`` with early stopping on validation loss.
306
307    After each epoch the validation loss is computed; training stops once it
308    has not improved for ``patience`` epochs, and the weights from the best
309    epoch are loaded back into ``model``.
310
311    Parameters
312    ----------
313    model : torch.nn.Module
314        Model from :func:`build_model`. Modified in place.
315    train_df, val_df : pandas.DataFrame
316        Metadata for training and validation (see :class:`FrameDataset`).
317        ``train_df`` must contain both classes.
318    size : int, default ``config.DEFAULT_IMAGE_SIZE``
319        Image side length.
320    epochs : int, default 30
321        Maximum number of epochs.
322    batch_size : int, default 64
323    lr : float, default 1e-3
324        AdamW learning rate. Use a smaller value (e.g. 1e-4) for a full
325        fine-tune.
326    weight_decay : float, default 1e-4
327        AdamW weight decay.
328    patience : int, default 5
329        Epochs without validation-loss improvement before stopping.
330    augment : bool, default True
331        Random flips and brightness changes on the training images.
332    seed : int, default ``config.DEFAULT_SEED``
333        Seed for batch shuffling and augmentation.
334    device : str, optional
335        Torch device; defaults to :func:`default_device`.
336    verbose : bool, default False
337        Print one line per epoch.
338
339    Returns
340    -------
341    TrainResult
342        The model (best weights, eval mode), the per-epoch history and the
343        best epoch (1-based).
344
345    Raises
346    ------
347    ValueError
348        If a hyperparameter is out of range, ``train_df`` lacks a class, or
349        the model has no trainable parameters.
350    """
351    if epochs < 1 or batch_size < 1:
352        raise ValueError("epochs and batch_size must be at least 1")
353    if lr < 0 or weight_decay < 0 or patience < 0:
354        raise ValueError("lr, weight_decay and patience must be non-negative")
355    device = device or default_device()
356    pos_weight = compute_pos_weight(train_df[LABEL_COLUMN])
357    params = [p for p in model.parameters() if p.requires_grad]
358    if not params:
359        raise ValueError("model has no trainable parameters")
360
361    train_loader = DataLoader(
362        FrameDataset(train_df, size, augment=augment, seed=seed),
363        batch_size=batch_size,
364        shuffle=True,
365        generator=torch.Generator().manual_seed(seed),
366    )
367    val_loader = DataLoader(FrameDataset(val_df, size), batch_size=batch_size)
368
369    model.to(device)
370    criterion = nn.BCEWithLogitsLoss(pos_weight=torch.tensor(pos_weight, device=device))
371    optimiser = torch.optim.AdamW(params, lr=lr, weight_decay=weight_decay)
372
373    history = []
374    best_loss, best_epoch, epochs_without_improvement = float("inf"), 0, 0
375    best_state = copy.deepcopy(model.state_dict())
376    for epoch in range(1, epochs + 1):
377        t0 = time.perf_counter()
378        set_train_mode(model)
379        total, n = 0.0, 0
380        for x, y in train_loader:
381            x, y = x.to(device), y.to(device)
382            optimiser.zero_grad()
383            loss = criterion(model(x).squeeze(1), y)
384            loss.backward()
385            optimiser.step()
386            total += loss.item() * len(y)
387            n += len(y)
388        val_loss = _mean_loss(model, val_loader, criterion, device)
389        history.append({
390            "epoch": epoch,
391            "train_loss": total / n,
392            "val_loss": val_loss,
393            "seconds": time.perf_counter() - t0,
394        })
395        if verbose:
396            h = history[-1]
397            print(f"epoch {epoch:3d}  train {h['train_loss']:.4f}  val {val_loss:.4f}  ({h['seconds']:.1f} s)")
398
399        if val_loss < best_loss:
400            best_loss, best_epoch, epochs_without_improvement = val_loss, epoch, 0
401            best_state = copy.deepcopy(model.state_dict())
402        else:
403            epochs_without_improvement += 1
404            if epochs_without_improvement >= patience:
405                break
406
407    model.load_state_dict(best_state)
408    model.eval()
409    return TrainResult(model, history, best_epoch)

412@torch.no_grad()
413def predict_proba(model, df, size=config.DEFAULT_IMAGE_SIZE, batch_size=64, device=None):
414    """Probability of under-extrusion for each image in ``df``.
415
416    Parameters
417    ----------
418    model : torch.nn.Module
419        Trained model.
420    df : pandas.DataFrame
421        Metadata (see :class:`FrameDataset`).
422    size : int, default ``config.DEFAULT_IMAGE_SIZE``
423        Must match the size used in training.
424    batch_size : int, default 64
425    device : str, optional
426        Torch device; defaults to :func:`default_device`.
427
428    Returns
429    -------
430    numpy.ndarray
431        Probabilities in [0, 1], shape ``(len(df),)``, in ``df`` order.
432    """
433    device = device or default_device()
434    model.to(device).eval()
435    loader = DataLoader(FrameDataset(df, size), batch_size=batch_size)
436    probs = [torch.sigmoid(model(x.to(device)).squeeze(1)).cpu() for x, _ in loader]
437    return torch.cat(probs).numpy()

440@torch.no_grad()
441def predict_proba_images(model, images, batch_size=64, device=None):
442    """Probability of under-extrusion for images already in memory.
443
444    Used for robustness tests, where images are corrupted before prediction.
445
446    Parameters
447    ----------
448    model : torch.nn.Module
449        Trained model.
450    images : numpy.ndarray
451        Float array of shape ``(N, H, W, 3)`` with values in [0, 1].
452    batch_size : int, default 64
453    device : str, optional
454        Torch device; defaults to :func:`default_device`.
455
456    Returns
457    -------
458    numpy.ndarray
459        Probabilities in [0, 1], shape ``(N,)``.
460    """
461    images = np.asarray(images)
462    if images.ndim != 4 or images.shape[-1] != 3 or len(images) == 0:
463        raise ValueError(f"expected a non-empty (N, H, W, 3) array, got shape {images.shape}")
464    device = device or default_device()
465    model.to(device).eval()
466    probs = []
467    for start in range(0, len(images), batch_size):
468        x = torch.from_numpy(np.ascontiguousarray(images[start : start + batch_size], dtype=np.float32))
469        x = normalise(x.permute(0, 3, 1, 2))
470        probs.append(torch.sigmoid(model(x.to(device)).squeeze(1)).cpu())
471    return torch.cat(probs).numpy()
